Usage Notes
Citation
If these data are used in published research, please cite:
Son H and Yi G-S. SynerGPCR: an AI-augmented GPCR assay chain database for synergistic clinical translatability. Manuscript in preparation. A citable DOI will be added upon publication.
AI Predictions
GPCRact predictions in these files are computationally generated and have not been independently confirmed in the laboratory — see the AI Prediction tab for full methodology and performance metrics. When using gpcract_predictions.csv, note the confidence thresholds applied (L2 — G-Protein Coupling: t ≥ 0.40; L3 — β-Arrestin Recruitment: t ≥ 0.97) and cite the GPCRact paper:
Son H and Yi G-S (2026). GPCRact: a hierarchical framework for predicting ligand-induced GPCR activity via allosteric communication modelling. Briefings in Bioinformatics, 27(1), bbaf719. https://doi.org/10.1093/bib/bbaf719
Data Sources
SynerGPCR integrates data from 10 public repositories. Please refer to the original sources when re-distributing raw assay data.
  • ChEMBL — large-scale bioactivity database (EMBL-EBI)
  • BindingDB — protein–small molecule binding affinities
  • PubChem BioAssay — high-throughput screening data (NCBI)
  • IUPHAR/BPS Guide to PHARMACOLOGY — curated receptor–ligand pharmacology
  • DrugBank — approved drug and target information
  • DrugCentral — drug indications and pharmacological actions
  • DGIdb — drug–gene interaction database
  • TTD — Therapeutic Target Database
  • GLASS — GPCR–ligand association database
  • GPCRdb — GPCR structure, function, and pharmacology
