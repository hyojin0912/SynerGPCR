Usage Guide
{# ── How to Search ── #}
How to Search
1 — Name or identifier (navbar autocomplete) Enter a compound name, InChIKey, gene symbol, UniProt accession, or disease name into the search bar (minimum 2 characters). Results are ranked in order: gene symbol prefix → compound name prefix → disease name prefix → protein name contains → compound name contains → disease contains → InChIKey exact → UniProt exact. Selecting a result navigates directly to the corresponding compound, target, or disease page.
2 — Structure similarity (SMILES fallback) If your compound is not found by name or InChIKey, enter a valid SMILES string. SynerGPCR will compute an ECFP4 fingerprint (Morgan radius 2, 2048 bits) and search 277,544 assay-bearing compounds by Tanimoto similarity (threshold 0.5). The most similar compounds and their assay chain profiles are returned. If no results appear, the scaffold has no close precedent in public GPCR assay data.
3 — Browse without a search term Navigate to the Browse tab to explore four pre-built views: GPCR Targets, Approved Drugs, AI Candidates, and Disease Explorer. No search term is required.

Understanding Assay Layers and AI Predictions
{# ── Chain diagram colour coding ── #}
Reading the Assay Chain Diagram

Each compound page displays an assay chain pipeline showing activity at four mechanistically ordered layers. Node colours indicate the evidence type:

Experimentally active Experimentally inactive No experimental data AI-predicted active
For a full description of each assay layer and the Bliss Synergy Index methodology, see the About page.
{# ── AI Prediction confidence ── #}
How AI Predictions Are Generated

GPCRact (an E(n)-equivariant graph neural network) predicts L2 (G-Protein Coupling) and L3 (β-Arrestin Recruitment) activities from 3D structural graphs of the GPCR binding site and the ligand. Each prediction produces three outputs:

  • binding_prob — probability that the compound binds the receptor (Stage 1 binding head; binder if ≥ 0.5).
  • ago_prob / ant_prob — softmax probabilities for agonist vs. antagonist activity (Stage 2 activity head; predicted MoA = argmax of the two).
  • confidence = binding_prob × max(ago_prob, ant_prob). A compound is classified AI-active when binding_prob ≥ 0.5 and confidence ≥ the operating threshold (L2: 0.40 / L3: 0.97). The operating threshold for each layer was selected to maximise the Bliss Synergy Index margin over the Monte Carlo random-assignment null.

AI predictions are shown only for the 151 GPCR targets with sufficient 3D structural data. Predictions for peptide- and glycoprotein-hormone receptors (e.g. GLP1R, PTH1R) are excluded due to compound-modality mismatch with the training set.

{# ════════════════════════════════════════════════════════ SECTION 3 — Data Access ════════════════════════════════════════════════════════ #}
Data Access and Download

All SynerGPCR datasets are freely available from the Download page. The following files are provided:

  • compound_lookup.csv — compound metadata (name, SMILES, clinical phase, approval status) for all assay-bearing compounds.
  • target_lookup.csv — GPCR target metadata (gene symbol, UniProt accession, GPCR class/family, AI prediction availability) for all 600 targets.
  • compound_chain_summary.csv — pair-level assay chain records: the experimental activity state at each layer for every compound–GPCR pair (396,169 pairs).
  • gpcract_predictions.csv — high-confidence GPCRact AI predictions for L2 (G-Protein Coupling) and L3 (β-Arrestin Recruitment); 104,641 retained prediction cells across 151 GPCR targets.
  • candidate_shortlist.csv — the 1,179 AI-augmented synergy candidates where GPCRact supplies a missing L2 or L3 state.
  • synergy_stats.csv — Bliss Synergy Index values for all observed chain patterns.
  • single_layer_table.csv — single-layer approval rates and compound counts used for SI calculation.
REST API

All data are accessible programmatically via a REST API (base URL: https://synergpcr.kaist.ac.kr, no authentication required). Key endpoints:

Endpoint Method Description

Frequently Asked Questions
{# Q1 — Bliss SI #}

The Bliss Synergy Index (SI) quantifies how much the observed clinical approval rate of a compound group exceeds the rate expected if each assay layer contributed independently.

SI = observed approval rate / EBliss, where EBliss = 1 − Π(1 − PLi) and PLi is the single-layer approval rate for each layer included in the pattern. SI > 1 indicates synergistic clinical enrichment beyond statistical independence.

A full derivation and a worked example are provided on the About page.
{# Q2 — Compound not found #}

SynerGPCR covers 277,544 compounds with at least one assay record against a GPCR target. If your compound is not found by name or InChIKey, enter a valid SMILES string into the search bar. SynerGPCR will search for structurally similar compounds using Tanimoto similarity (ECFP4, threshold 0.5). If no results appear, your compound's scaffold has no close precedent in public GPCR assay data.
{# Q3 — Co-active #}

A compound is counted as co-active at a target when it has experimental activity at both Receptor Binding (L1) and G-Protein Coupling (L2) at the same target — downstream L3/L4 activity is not part of this criterion. The conditional approval rate among co-active compounds is shown alongside the pooled baseline (1.40%, computed across all 211 targets with experimental co-active data), correcting for the trivial enrichment that heavily-screened targets would otherwise show due to selection bias.
{# Q4 — No AI predictions #}

GPCRact requires a 3D structural model of the GPCR binding site. Only 151 of 600 GPCR targets in SynerGPCR have sufficient structural data for high-confidence predictions.

Additionally, predictions for certain peptide- and glycoprotein-hormone receptors (e.g. GLP1R, PTH1R) are excluded: GPCRact was trained primarily on small-molecule data, and predictions against receptors whose endogenous ligands are peptides or glycoproteins cannot be considered reliable due to the mismatch in compound modality. Where AI predictions are absent, only experimental data are shown.
{# Q5 — Beta-arrestin caution #}

β-Arrestin Recruitment assays can reflect biased agonism — a ligand preferentially activating one downstream signalling pathway over another. In addition, empirical data in SynerGPCR show a strong statistical dependency between G-Protein Coupling and β-Arrestin Recruitment activity (Fisher OR = 9.24, p ≈ 0), which violates the independence assumption underlying the Bliss Synergy Index. For these reasons, β-Arrestin Recruitment results should be read as a supplementary signal rather than a standalone measure of GPCR activity, and synergy values for chain patterns that include this layer carry an explicit caveat.
{# Q6 — Download AI predictions #}

Yes. The complete high-confidence prediction set (104,641 cells across 151 GPCR targets) is available as gpcract_predictions.csv from the Download page. This file contains only retained records that passed all quality filters: confidence ≥ 0.40 for G-Protein Coupling predictions and ≥ 0.97 for β-Arrestin Recruitment predictions.
