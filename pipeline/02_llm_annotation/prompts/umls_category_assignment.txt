LLM CALL SPECIFICATION
================================================================================
Stage              : UMLS CUI / disease name -> 1 of 12 therapeutic-area categories
Notebook           : 02_llm_annotation/umls_to_category.ipynb
Input              : Output/DB/GPCRactDB/Raw_Disease_List.csv (5,381 rows;
                     columns umls_cui | disease_name | source_hint)
Output tables      : Output/DB/GPCRactDB/UMLS_CUI_to_Category_v2.csv (5,079 rows,
                     input disease_name retained next to the assigned category)
                     Output/DB/GPCRactDB/category_checkpoint.csv (2,203 rows)
                     -> disease_category_lookup.csv (the 12 categories)

Model              : gemini-2.5-flash-lite
Temperature        : 0.0
generation_config  : genai.GenerationConfig(temperature=0.0)
Response format    : free-form JSON object {disease_name: category_number},
                     markdown fences stripped by regex before json.loads
Batching           : GEMINI_BATCH_SIZE = 30 disease names per call
Checkpointing      : CHECKPOINT_EVERY = 10 batches; resumable
Random seed        : none -> NOT deterministic even at temperature 0.0

HYBRID DESIGN — READ THIS
  The LLM is the SECOND stage. `rule_based_category()` (deterministic keyword
  matching) runs first over all classifiable rows; the LLM is called only for the
  remainder. Rows whose disease_name is in {NOT_FOUND, INVALID_FORMAT, Unknown,
  Unknown disease} are excluded from classification entirely.

  A separate, earlier LLM call in the same notebook resolves CUI -> disease name
  for CUIs not covered by the source files (~15% of CUIs; ~85% come from
  ChEMBL > DrugBank > IUPHAR > TTD file lookup, in that priority order).

CATEGORY ENUM (12)
  1 CNS / Psychiatric        2 Cardiovascular          3 Metabolic / Endocrine
  4 Inflammatory / Immune    5 Respiratory             6 Oncology / Cancer
  7 Renal / Urological       8 Gastrointestinal        9 Pain / Musculoskeletal
 10 Reproductive / Hormonal 11 Infectious Disease     12 Other / Unclassified

VALIDATION
  The returned category is cast to int; any value outside 1..12, and any
  ValueError/TypeError on the cast, is coerced to 12 (Other / Unclassified).

RETRY POLICY
  None at this call site. A single try/except wraps each batch; there is no retry
  loop and no backoff.

FALLBACK ON FAILURE
  On any exception the ENTIRE batch of up to 30 CUIs is assigned category 12
  (Other / Unclassified): `return {cui: 12 for cui in name_to_cui.values()}`.
  CONSEQUENCE: category 12 is a mixture of genuine "other/unclassified" diseases,
  out-of-range model answers, and whole failed batches. Do not read the size of
  category 12 as a biological result.
